모아북 화면 무드: A와 C

원본 무드 보드의 규격과 SVG 에셋을 기준으로 복원한 A/C 디자인입니다. 아래 화면은 최신 Flutter iPhone 17 시뮬레이터 실측 캡처입니다. 전체 26개 화면 × 2개 스타일은 비교 갤러리에서 확인할 수 있습니다.

전체 화면·서가 페이지 비교아이콘 교체 비교원본 무드 보드A 디자인 가이드C 디자인 가이드

구현: 컬렉션에는 실제 표지 9권을, 기본 서가에는 가상의 샘플을 더해 총 90권을 사용합니다. 서가는 3단으로 표시하고 좌우 드래그로 페이지를 넘깁니다. 책 추가는 상단의 작은 + 버튼으로 배치하며, 두 서가 모두 같은 우측 최상단에 톱니 설정이 있습니다. 아래 SVG는 원본 에셋이며, 글자가 있는 SVG는 앱에서 번들 폰트로 다시 그립니다. 책등 폭은 22~38px이며 작가명·띠지 문자를 빼고 제목만 세로로 표시합니다. C 탭 버튼의 색 면은 하단 안전 여백까지 전체를 채웁니다. 일반 버튼과 A 옵션은 최신 요청에 따라 8px 둥근 모서리를 사용합니다. 독서카드의 별도 기록 보기 버튼과 앞뒤 인디케이터는 제거했으며, 카드 터치·좌우 스와이프로 전환합니다. 아래 원본 SVG와 규격은 참고 기준이며, 최신 구현은 캡처에 표시됩니다. 빈 이미지 색과 치수는 원본 설계 기준으로 함께 보관합니다.

사용 규칙 (제안)

  1. 색은 띠지와 강조에만 크게 쓴다. 바탕과 글자는 종이색과 잉크색 두 가지로 유지한다.
  2. 괘선 종이, 스탬프, 인덱스 탭은 독서카드 안에서만 쓴다. 서가와 컬렉션에는 쓰지 않는다.
  3. 띠지 색은 저장 이유 종류에 묶는다. 새 종류가 생기기 전에는 색을 더하지 않는다.
  4. 그림자는 큰 표지 한 곳에만 쓴다. 목록의 작은 표지에는 쓰지 않는다.
  5. 컬렉션·서가 제목만 명조(Gowun Batang)를 쓴다. 나머지는 Plex Sans KR.
  6. 카드·책등은 직각, 일반 버튼은 8px 라운드, 기록 추가 버튼은 원으로 구분한다.

사용 규칙 (제안)

  1. 굵기는 600까지만 쓴다. 제목이 무거워 보이면 크기를 줄이기보다 자간(-.02em)으로 정리한다.
  2. 한 화면에 큰 색 면은 두 개까지만 쓴다. 예: 독서카드 앞면은 주황 히어로 + 라임 띠지.

  4. 보라는 상태·종류 칩과 WISH 띠지에만 쓴다.
  5. 띠지 글자는 검정으로 하고, 보라 면만 흰 글자를 쓴다.
  6. 면은 직각, 칩과 버튼은 둥글게 한다. 일반 실행 버튼은 사용자의 최신 선호에 따라 8px 라운드를 사용한다.
