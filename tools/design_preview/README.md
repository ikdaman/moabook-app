## 실행

프로젝트 루트에서:

```sh
cd tools/design_preview
flutter pub get
flutter run -d 'iPhone 17'
```

서가 우측 설정 아이콘에서 A/C를 전환합니다. 책 추가 → 검색/촬영/갤러리 → 책 정보 → 세 가지 저장 상태 → 독서카드 → 기록 추가 흐름을 확인할 수 있습니다. 주제서가 제목을 누르면 나의 컬렉션이 열립니다.

기존 앱의 네이티브 플러그인에 영향을 받지 않도록 별도의 가벼운 iOS 호스트를 사용합니다. 기존 앱 진입점은 유지합니다.

## 전체 화면 다시 캡처

Flutter 실행 로그에 표시된 Dart VM Service URL을 사용합니다. 다른 터미널에서 프로젝트 루트로 이동한 뒤:

```sh

python3 scripts/capture_design_previews.py --vm-url '<Dart VM Service URL>' --device '<시뮬레이터 UDID>'
```

실제 `simctl io screenshot`으로 52개의 원본 PNG(현재 iPhone 17: 1206×2622)를 저장하고 비교 갤러리와 manifest를 생성합니다. 화면 레지스트리는 `packages/moabook_reading_ui/lib/src/sample_data.dart`에 있습니다.

원본 Claude 무드 보드의 가이드와 12개 SVG를 직접 확인해 `assets/design_preview/reference/`에 보관했습니다. 원본 텍스트 SVG는 서체를 유지하도록 앱에서 네이티브 Text로 그립니다. C 4단 계단은 원본 SVG를 사용하고, A 스탬프는 텍스트를 분리한 SVG 윤곽과 Plex Mono를 결합했습니다. 괘선은 원본의 1px / 32px 규격을 카드 크기에 맞춰 반복합니다.

- A: 1.5px 잉크 선과 책등 테두리, 3px 선반, 32px 이유 띠지. 큰 표지 뒤에는 6×6px 단색 그림자와 표지 위 컬러 띠지. 카드의 인덱스 탭·코발트 날짜 스탬프·괘선 복원.
- C: 검정 계열 책등, 4px 라임 선반, 주황 히어로·탄색 4단 계단·라임 점 2개. 표지의 3px 검정 테두리와 6×6px 그림자. 앞면 기록 박스의 흰 1.5px 선과 라임 숫자, 뒷면 주황 헤더와 개별 타임라인 카드 복원.

독서카드에는 별도 “카드 뒤의 기록 보기” 버튼과 앞뒤 인디케이터를 두지 않습니다. 앞면 카드 자체 또는 기록 영역을 누르면 기록으로 이동하고, 좌우 스와이프로 앞뒤를 전환합니다. 기록 추가 컨트롤은 별도로 동작합니다.

아이콘은 Phosphor bold 계열로 교체했습니다. 기본 서가는 책등, 주제 서가는 표지 격자를 사용하고 활성 탭은 같은 아이콘의 fill 변형을 사용합니다. `icons-preview.html`에서 기존 Lucide와 새 아이콘을 나란히 비교할 수 있습니다.

## 3단 서가와 페이지 이동

기본 서가는 실제 표지 9권 + 가상의 샘플 81권, 총 90권입니다. 컬렉션의 9권은 유지합니다. 책등 폭 22~38px과 5px 간격으로 줄마다 들어가는 책 수를 계산하고, 페이지마다 선반 3줄을 화면 안에 표시합니다. 좌우 드래그로 이동하며 독서카드를 열었다 돌아와도 이전 페이지를 유지합니다. 책 추가는 제목 옆의 작은 + 컨트롤입니다. 기본/주제 서가 및 목록 페이지에 같은 우측 최상단 톱니 설정을 사용합니다.

가상 책의 독서카드는 제목을 그린 샘플 표지를 사용합니다. 캡처 도구는 기본 52장에 더해 각 스타일의 서가 2페이지부터 마지막까지 캡처하고, 전체 비교 갤러리의 기본 서가 항목 아래에 표시합니다. VM 확장은 선택 매개변수 `page`를 지원합니다.


## 2026-10-17 피드백 반영

주제 서가는 최신 생성순으로 진입하며, 좌우 스와이프로 책장을 넘긴다. 목록은 제목 우측 메뉴로 열고 마지막 페이지에는 새 책장 만들기를 둔다. 기본/주제 탭 간 스와이프는 없다. 다음 책장과 마지막 화면을 캡처 항목에 추가해 28개 화면 × A/C와 기본 서가 추가 4장, 총 60장을 제공한다.

이유 없는 책의 띠지와 `저장 이유 없음` 표기를 제거하고, 주제 서가 샘플은 대부분 띠지 없는 책으로 구성했다. 미확정 추천/WISH/선물/소개 칩과 범례를 제거했다. 기존 색 매핑은 변경하지 않았다. 공통 빈 화면의 아이콘 박스를 없애고 책 추가를 `+ 책 추가`로 표시한다. 독서카드는 기존 구성을 유지하며 서체와 메타 정보, 타임라인 장식을 정돈했다. 기록 작성의 본문·메모·날짜 입력만 직각 모서리로 바꾸고 다른 입력 스타일은 유지했다.

기획 확인이 필요한 컬렉션 부제목·편집 범위·현재 컬렉션 표시·문장/페이지 입력은 유지했다. 별도 제외 요청한 컬러칩 변경, 표지 테두리 조정, 독서카드 영역 재구성은 반영하지 않았다. 디자인 가이드의 원본 SVG 예시는 참고 자료이며, 최신 반영 화면은 실제 캡처에서 확인한다.

띠지 위치 보정: 주제 서가의 저장 이유 문구는 표지 아래 별도 영역이 아니라 표지 하단 위에 겹쳐 표시한다. 이유 없는 책에는 띠지를 표시하지 않는다.

추가 요청 반영: 버튼·선택 칩·입력창·날짜 선택·선택 표시·기록 추가 버튼·시트의 모서리를 모두 직각으로 통일했다. 히어로의 장식용 점과 아이콘 도형은 유지한다.

## 2026-11-08 서가 경계 탐색 변경

기본 서가 마지막 페이지에서 왼쪽으로 밀면 주제 서가 첫 컬렉션으로 넘어간다. 첫 컬렉션에서 오른쪽으로 밀면 기본 서가 마지막 페이지로 복귀한다. 화면 슬라이드를 완료한 다음 서버를 갱신하며 기존 캐시를 유지한다. 실제 서버 컬렉션 목록은 응답의 역순으로 표시한다. 위 2026-10-17 항목의 기본/주제 탭 간 스와이프 없음 규칙은 이 변경으로 대체한다.
