## 재기획 시 확인할 문제

- 책 정보 샘플에 제목·저자와 소개문이 서로 다른 책의 내용으로 섞여 있다. 정보 구조를 검토하되 샘플 값을 실제 책 데이터로 확정하지 않는다.
- 저장 단계의 상태명은 읽고 싶은 책 / 읽고 있는 책 / 읽은 책이고, 기록 추가는 읽는 중 / 읽고 싶은 책 / 다 읽은 책 / 쉬고 있음이다. 상태명과 상태 전이 규칙을 통일할 필요가 있다.
- 이유 입력에는 `0/400`이 있지만 이유의 카테고리 선택 UI는 이 섹션에서 확인하지 못했다. 추천 / WISH / 선물 / 소개를 정식 데이터로 둘지 별도 결정이 필요하다.
- 시작·종료일이 있는 저장안은 상태별 날짜 필수 여부를 명확히 해야 한다.
- 주제 서가와 컬렉션의 명칭, 같은 책을 여러 컬렉션에 넣는 규칙, 삭제 시 기본 서가와의 관계를 확정해야 한다.

## 2026-10-09 디자인 프리뷰 반영

사용자와 논의한 결과 컬렉션 명칭을 유지하고, 주제서가 제목(`인생 책 LIST ▾`)을 컬렉션 목록 진입점으로 구현했다. 목록에서 컬렉션을 선택하면 해당 주제서가로 돌아간다. 책 저장의 세 상태와 이유/날짜 입력은 유지했고, 독서카드에서 기록 추가 진입을 명시했다.
