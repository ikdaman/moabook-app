# 2026-11-10 독서 화면 정책 변경

이 문서는 2026-11-07의 책 저장·첫 기록 분리 UI 및 과거의 마지막 추가 상태 우선 규칙을 대체한다.

- 새 책 저장은 읽고 싶은 책 / 읽고 있는 책 / 읽은 책 중 하나가 항상 선택되어 있다.
- 읽고 싶은 책은 선택 이유(400자), 읽고 있는 책은 시작일, 읽은 책은 완료일을 받는다. 날짜 기본값은 오늘이다.
- 현재 API에서는 책 생성 후 선택한 상태 기록을 한 번 생성한다. 책 생성과 기록 생성의 성공 여부를 따로 보관해 재시도 중복을 막는다. 기록 응답이 불확실하면 재전송하지 않고 독서카드에서 확인하게 한다.
- 기록 종류 선택에서는 현재 독서 상태 하나를 기본 선택 표시한다. 구매·문장 등 다른 기록을 작성해도 기존 독서 상태가 자동 변경되지는 않는다.
- 독서카드 상태는 상태 기록(TODO / INPROGRESS / DONE) 중 기록 날짜가 가장 최근인 것을 따른다. 같은 날짜면 나중에 생성된 기록을 따른다. 날짜가 오래된 상태를 나중에 추가해도 현재 상태를 덮어쓰지 않는다.
- 서버 기록 응답에 생성 시각이 있으면 생성 시각, 그렇지 않으면 기록 ID를 동률 판정에 사용한다. 둘 다 빠진 구형 응답은 최신순 응답 위치를 사용하므로, 모든 클라이언트에서 동일 날짜 동률을 확실히 보장하려면 서버가 생성 시각 또는 recordId를 제공해야 한다.
- 기록 종류·상세 입력 바텀 시트에서 반복되는 책 썸네일·제목·저자를 제거한다.
- 책 정보의 페이지·출간일은 위아래 3px 구분선과 강조된 숫자 스타일로 표시한다. 없는 값은 숨긴다.
- 띠지 텍스트는 화면·저장 이미지 모두 흰색이다.
- 컬렉션 저장 이미지는 항상 1080×1720의 9칸 영역을 유지하며, 빈 슬롯을 압축하지 않는다.

## 책 저장 시트 원본 대조

Safari에서 열린 [정책서](https://claude.ai/artifact/CGrhmuG8FsCce51VeHxWUy)의 화면 20·21·22를 직접 확인했다. 질문은 “지금 이 책과 어떤 사이인가요?”이며, 상태 버튼은 높이 42px와 비선택 항목의 연한 테두리·텍스트를 사용한다. 이유 입력란은 120px이고 선택 표시를 작은 회색 글자로 구분한다. 날짜는 18px 숫자로 표시하며 시작·완독 입력 아래에 “책과 함께한 시간을 독서카드에 남겨요.”를 표시한다.

## 후속 기록 추가 흐름

화면 20·21·22는 최초 책 저장에만 사용한다. 사용자가 Safari 정책서 화면 28·29·30·31을 다시 확인하도록 지시한 뒤 원문 흐름으로 수정하기로 확정했다. 독서 상태·책 수령·순간 기록 모두 선택한 카테고리의 입력 화면으로 이동하고, 날짜와 내용을 확인한 뒤 “기록 완료”로 저장한다. 이전의 책 수령·순간 기록 즉시 저장 지시는 이 확정으로 대체한다.

기록 종류 선택 화면에는 “자유 기록” 버튼만, 내용 입력 화면에는 “기록 완료” 버튼만 표시한다. 두 버튼은 검정 배경·흰색 글씨의 기본 주요 버튼 스타일을 유지한다. 날짜는 입력 화면에서 선택한다. 구매·마음에 든 문장 등 일반 카테고리는 “어떤 기억을 남기고 싶나요? · 선택”, 자유 기록은 같은 질문에 “· 필수”, 읽고 싶은 책은 “읽고 싶은 이유 · 선택”을 표시한다. 후속 사용자 확정으로 모든 카테고리의 내용은 400자로 제한하고 글자 수를 표시한다. 선택·필수 표시는 작고 흐린 글씨로 질문과 구분한다. 제목과 “카테고리 바꾸기”는 헤더 안에 모아 중복 여백을 두지 않는다. 자유 기록 입력에서 돌아오면 원래 선택한 카테고리를 복원한다.
