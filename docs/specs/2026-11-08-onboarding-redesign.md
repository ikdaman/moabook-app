# 첫 책을 고르는 튜토리얼

2026-11-08 작업 시작, 2026-11-09 최종 확인. 픽셀 게임 형태의 온보딩을 서문의 분위기로 바꿨다. 타이핑으로 말을 건네고 직접 첫 책을 고르는 경험은 유지한다.

## 화면 흐름

1. 먹색 배경·아이보리 명조체의 질문. 글이 완성될 때까지 버튼을 기다리게 하지 않으며, 타이핑 영역 높이를 미리 확보해 화면이 흔들리지 않게 한다.
2. 종이색 검색창과 표지·제목·저자가 있는 결과 목록. 빈 결과·검색 오류·재시도·다음 결과 로딩을 제공한다. 키보드가 열리면 질문을 간결하게 줄여 결과 공간을 확보한다.
3. 선택한 책을 보여주는 밝은 입력 시트. 읽고 싶은 이유는 선택이며 최대 400자다. 글자 단위는 이모지를 포함한 grapheme 기준이다. 본문만 스크롤하고 선택 버튼은 키보드 위에 유지한다.
4. 고른 책이 선반에 놓이는 1회 애니메이션. 선택한 제목과 이유를 확인한 뒤 로그인으로 이어진다. 완료 문구는 `첫 책을 골랐어요.`이며 서버에 저장됐다고 표시하지 않는다.
5. 본앱의 기록 종류 선택·작성 시트에서도 표지·제목·저자를 표시해 어떤 책의 기록인지 유지한다. 기존 카테고리·날짜·내용·저장 규칙은 바꾸지 않는다.

로그인 화면 하단의 `모아북 처음부터 둘러보기`로 다시 열 수 있다. 앱 삭제나 계정 초기화가 필요 없다.

## 저장과 이동 정책

- 로그인 전 책과 읽고 싶은 이유는 `PendingBook`에 임시 보관한다.
- `로그인하고 서가 시작하기`는 선택을 보존한다. `건너뛰기`는 선택을 비우고 로그인으로 간다.
- 책 저장은 로그인 후 기존 소비 흐름에서 수행한다. 책 저장만으로 기록을 자동 생성하지 않는다. 첫 독서 기록은 카드에서 사용자가 명시적으로 추가한다.
- 입력 시트를 닫으면 검색 화면에 남는다. 같은 책을 다시 선택하면 앞서 적은 이유를 불러온다.
- 첫 검색·다음 페이지·초기화 이후의 늦은 응답이 새 검색을 덮지 않도록 요청 세대를 확인한다.
- 모션 감소 설정에서는 타이핑·화면 전환·선반 도착을 즉시 표시한다. 타이핑 텍스트는 접근성에 전체 문장 한 번으로 제공한다.

## 검증

전체 테스트·정적 분석 결과는 [현재 체크리스트](../plans/2026-11-05-resume-checklist.md)를 따른다. 320px 화면과 키보드, 책 선택→이유→로그인 보존, 오류 재시도, 400개 이모지 제한, 늦은 검색/페이지 응답을 자동 검증한다.

`integration_test/onboarding_device_test.dart`는 샘플 검색 결과로 튜토리얼의 선택·메모·로그인 전달을 검증하고, 별도로 본앱의 빈 카드→기록 종류→자유 기록 입력→저장·목록 복귀를 검증한다. 실제 OAuth 성공이나 서버 저장을 대신하지 않는다. 서버 쓰기는 없고 SharedPreferences도 테스트 대체 구현을 써서 기기의 본래 온보딩 설정을 바꾸지 않는다. 기기 실행에는 `--keep-app-running`을 명시한다. 자동 입력은 테스트 키보드로 고정하며 실제 IME의 입력 상태 주입 충돌을 피한다. 작은 화면의 키보드 여백 배치는 별도의 위젯 테스트로 확인한다.

시각 확인용 캡처는 `output/device-qa/2026-11-08/tutorial/`에 로컬 보관한다. 표지가 없는 책은 제목을 넣은 대체 표지를 표시한다.

전체 Flutter 테스트 196개와 정적 분석이 통과했다. Android Profile 및 iOS 시뮬레이터 Debug에서 샘플 선택·이유·전달과 독립된 첫 기록 작성·저장·목록 복귀 통합 테스트가 통과했다. 실제 소셜 로그인 성공으로 간주하지 않는다.
