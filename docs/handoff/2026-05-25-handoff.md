## Phase 3 이후 버그 수정 이력 (2026-05-25)

| 버그 | 원인 | 수정 내용 |
|---|---|---|
| 구글 로그인 ID 토큰 null | `--dart-define-from-file` 미전달 + legacy `google_sign_in` | `CredentialManager` 방식으로 전환 (`MainActivity.kt` MethodChannel) |
| 내 서점 sort 파라미터 오류 | JSON 필드명(`createdDate`)을 sort에 사용 | JPA 엔티티 필드명 `createdAt` 으로 수정 |

| 삭제/독서 시작 피드백 없음 | 미구현 | `HomeState.snackbarMessage` + `ScaffoldMessenger` 추가 |

## Phase 5 개요 — 위젯 통합

### 5-A. Android Glance 이식
- `~/dev/moabook/widget/` 모듈 전체를 `android/app/src/main/kotlin/.../glance/` 로 이식
- `WidgetCache` read 경로: `DataStore("widget_cache")` → `SharedPreferences("HomeWidgetPreferences")`
- key / JSON 포맷 **동일 유지** (기존 사용자 cold-start 호환)

### 5-B. iOS WidgetKit 신규
- Xcode Widget Extension target 추가 (SwiftUI, S/M/L 3종)
- Apple Developer Portal에 `group.shop.moabook` App Group 등록 → Provisioning Profile 재발급
- `UserDefaults(suiteName: "group.shop.moabook")` 에서 JSON 디코딩

### 5-C. Flutter 브리지
- `lib/widget_bridge/widget_publisher.dart` — `home_widget` 패키지로 데이터 publish
- 홈 데이터 갱신 시마다 + 로그인 직후 1회 호출
