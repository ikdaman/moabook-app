## 목표와 범위

별도 프리뷰에 있는 새 UI를 정책에 맞춘 뒤 실제 앱의 서가·컬렉션·독서카드·기록 흐름으로 연결한다. 기존 로그인, 도서 검색, 촬영/OCR, 공유 확장, 위젯, 알림 진입도 새 화면에서 이어지게 한다.

이번 범위에는 서가/컬렉션 이미지 저장까지 포함한다. 기록 수정·삭제 UI, 컬렉션 삭제, 소셜 기능, 사용자 지정 띠지 색상은 추가하지 않는다. 삭제 폴더에 있는 수동 책 등록과 구 책 정보 편집은 개편 화면에서 제외한다. 알라딘 책 저장과 새 앞면 조회는 같은 주소를 재사용하므로 유지한다.

### 진행 원칙

- 정책에 확정된 화면 변경은 백엔드 답변을 기다리지 않고 진행한다.
- 미확정 API를 추측해 운영 데이터 저장을 구현하지 않는다. 해당 경계는 인터페이스와 명시적인 테스트용 구현으로 분리한다.
- 프리뷰와 실제 앱이 동일한 화면 컴포넌트를 사용하게 한다. 공통 UI 패키지와 서버 연결 코드를 분리하며, 기능별 컴포넌트 분리는 계속 진행한다.
- 화면 표시용 선택값·초안과 서버에 저장된 상태를 구분한다. 성공 전에는 완료 화면으로 이동하지 않는다.
- 각 단계는 작은 변경 묶음으로 검증한다. 최종 본앱 전환 전까지 기존 경로를 급하게 삭제하지 않는다.
- 디자인은 사용자가 지정한 마지막 정책서 스크린샷의 밝은 테마를 기준으로 한다. A/C 재선택을 선행 조건으로 두지 않는다.

체크 완료는 코드와 자동 테스트 기준이다. 인증된 개발 서버의 실제 데이터 검증 완료를 뜻하지 않는다. 최신 실행 결과는 문서 끝의 API 연동 작업 기록을 참고한다.

## 2. 정책 UI와 입력 동작 반영

## 2026-11-04 본앱·API 연동 작업 기록

- **개발 서버:** 사용자가 현재 주소가 개발 서버임을 확인했다. 본앱의 기존 `BASE_URL=https://moabook.shop`과 로그인 인증·토큰 갱신 Dio를 재사용한다. 별도 주소를 임의로 만들지 않았다.
- **공통 화면:** `packages/moabook_reading_ui`를 본앱과 독립 프리뷰가 함께 사용한다. 실제 앱은 gateway를 주입하고 프리뷰는 로컬 상태로 실행한다. 실제 앱에서 조회 실패를 샘플 책으로 대체하지 않는다.
- **연결한 기능:** 전체 서가 페이지 조회, 카드 앞면·기록 목록, 14종 기록 POST, 컬렉션 목록·9슬롯 상세·생성·이름 수정·책 빼기·기존 책 담기. 본앱 홈/검색/컬렉션/책 상세 경로에서 새 화면을 사용한다. 촬영·바코드·OCR·갤러리 선택 결과를 새 책 정보 화면으로 돌려준다.
- **저장 처리:** 응답을 받기 전에 성공으로 표시하지 않는다. 실제 서버 ID를 사용하며 중복 탭을 막는다. 실패 시 초안을 유지하고, 생성 응답이 유실돼 저장 여부가 불명확하면 재전송 대신 목록 확인을 안내한다. 컬렉션 생성 후 상세 조회만 실패한 경우 생성 ID를 유지한다.
- **상태 표시:** 현재 상태와 이유는 카드 응답을 표시한다. 날짜순 타임라인으로 현재 상태를 재계산하지 않는다. 추가 후 카드·기록을 다시 조회한다. 띠지의 날짜 우선 규칙은 실제 서버 확인이 남아 있다.
- **실제 요청 결과:** 인증 없는 개발 서버 `GET /mybooks/store`, `GET /collections`는 HTTP 500이었다. 인증된 책·기록 조회와 실제 POST/PUT 검증은 미실시다. 실제 알라딘 제목 검색은 HTTP 200 안에 오류 코드 999를 반환했다. 이를 결과 0권으로 숨기지 않고 검색 실패로 처리하도록 보완했다.
- **자동 검증:** 전체 Flutter 테스트 154개 통과, `flutter analyze` 경고·오류 없음. 실제 앱 Provider → 기존 인증 Dio → 새 API → 공통 화면 경로도 테스트 서버 어댑터로 확인했다. 실제 개발 서버에 대한 인증된 저장 테스트와는 구분한다.
- **빌드:** 본앱 iOS 기기용 Debug 무서명 빌드 성공(`build/ios/iphoneos/Runner.app`). 본앱 iPhone 17 시뮬레이터 실행은 기존 기기 전용 플랫폼 설정과 ML Kit의 arm64 시뮬레이터 지원 문제로 실패했다. 앞서 성공한 시뮬레이터 캡처는 플러그인이 없는 별도 프리뷰 호스트 결과다.
- **남은 작업:** 신규 책 저장 ID·정확한 중복 조회·첫 기록 연결, 알라딘 검색 오류 해소 및 실기기 촬영 검증, 인증된 개발 서버 저장/재시작 검증, 이미지 내보내기, 공유 확장·위젯 호환, 네이티브 시뮬레이터 빌드 문제 해결. 계정 전환·외부 진입 통합 검증도 남아 있다.

### 실행 설정

본앱: `flutter run --dart-define-from-file=env/prod.json` (파일명은 기존 명칭이며, 현재 주소는 사용자가 확인한 개발 서버다). 새 UI는 기본 활성화이며 필요 시 `--dart-define=USE_NEW_READING_UI=false`로 기존 화면을 사용할 수 있다.

서가 기본 계약은 문서의 `/mybooks/store` + `limit`이다. 서버 main의 `/mybooks` + `size` 계약을 쓰는 배포에서는 `--dart-define=READING_SHELF_PATH=/mybooks --dart-define=READING_PAGE_SIZE_KEY=size`를 명시한다. 실패 시 다른 주소를 자동 탐색하거나 조용히 전환하지 않는다. 인증된 배포 응답 확인 후 환경값을 확정한다.
