# 모아북 — 현재 작업 상태

> **2026-11-08 후속:** 사용자 요청으로 Android 실기기 검증을 재개했다. 검색 무한 스크롤, 글자 잘림 수정, 세로 고정을 반영했다. 최종 사용자 선택으로 앱 글자 크기는 시스템 폰트 배율을 따르지 않고 고정한다. 전체 Flutter 테스트 169개와 정적 분석 통과. 실제 검증·남은 서버/디자인 문제·테스트 데이터 정리는 [실기기 검증 결과](../specs/2026-11-08-android-device-qa.md)를 기준으로 한다. 아래의 미검증·제외 항목은 11월 7일 이전 작업 이력을 포함한다.

2026-11-07 갱신. 이전 중단 시점의 대기 항목을 최신 사용자 합의와 구현 상태로 교체한다. API 상세는 [최신 반영 문서](../specs/2026-11-07-api-update.md)를 참조한다.

## 확정한 범위

- 밝은 테마를 구현 기준으로 한다.
- 도서 검색은 YES24를 백엔드 경유로 사용한다. 키는 앱에 넣지 않는다.
- 홈 화면 위젯과 OCR 책 인식, 표지 촬영·갤러리 입력·이미지 공유 인식은 제거한다.
- **바코드 스캔은 유지한다.** 정책서의 스캔 화면과 ISBN 인식 흐름을 남긴다.
- 서가·컬렉션 이미지를 사진에 저장하는 기능은 유지한다.
- 책만 저장하며 기록은 자동 생성하지 않는다. 빈 독서카드의 `첫 기록 남기기` 버튼에서 별도로 작성한다.
- 기존 알라딘 책은 모두 제거됐으므로 이관·출처 간 ISBN 중복 판별은 필요 없다.
- 사용자가 이번 작업에서 **실계정 검증과 최종 iOS/Android 빌드(이전 목록의 4·5번)를 제외**했다. 해당 작업은 수행하지 않았다.

## API 확인 상태

- ISBN 상세조회 명세를 확인하고 `Yes24DataSource.searchByIsbn()`에 `GET /books/detail`, `searchType=ISBN13`, `query`를 연결했다. 단일 객체 응답을 파싱하고 스캔한 ISBN을 보존한다.
- 서가 페이지 크기는 문서 표의 `limit`을 사용한다. 예제 이름의 `size`와 불일치는 실제 서버 검증 때 확인한다.

## 이번 검증

- ISBN 상세조회 후속: 관련 Flutter 테스트 20개 통과, `flutter analyze --no-pub` 문제 없음.

- `flutter test --no-pub --reporter expanded`: **160개 통과**. 삭제한 OCR 기능 전용 테스트는 함께 제거했다.
- `flutter analyze --no-pub`: 문제 없음.
- 실제 표지 파일·표지 없음·긴 제목·긴 이유를 넣은 1/4/9권 및 마지막 페이지 PNG를 생성하고 직접 확인했다.
- 이미지 저장 권한 거부·중간 실패·남은 이미지만 재저장은 주입한 저장 함수로 검증했다. 이번 작업에서 기기의 사진 보관함에 쓰는 통합 테스트는 실행하지 않았다.
- CocoaPods 의존성 갱신과 Xcode 프로젝트 구조/entitlements/plist·Ruby 문법만 확인했다. 네이티브 빌드는 실행하지 않았다.
- 실계정 로그인·인증된 서버 조회·저장·삭제는 수행하지 않았다.

## Android 실기기 설치 후속

2026-11-07 사용자 요청으로 Android 빌드·설치를 재개했다. 카메라 플러그인과 충돌한 `WRITE_EXTERNAL_STORAGE`의 `maxSdkVersion`은 앱의 기존 값(29)을 유지하도록 Manifest 병합 규칙을 추가했다. `flutter build apk --debug --dart-define-from-file=env/prod.json` 성공 후 Galaxy A52s(SM-A528N)에 기존 앱을 유지하는 업데이트로 설치했다. 설치 버전은 2.0.21(56)이며 MainActivity 실행과 프로세스 유지를 확인했고, 확인 시점의 오류 로그에는 AndroidRuntime/Flutter 오류가 없었다. 실제 책 바코드 인식→조회→선택·저장 흐름은 아직 확인하지 않았다. iOS 빌드는 수행하지 않았다.
