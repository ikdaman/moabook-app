- [x] 동시 401 요청의 1회 토큰 갱신·재시도, 갱신 서버 500에서 로그인 유지, 갱신 거절 시 토큰 삭제·만료 이벤트를 모의 서버로 검증.

- [x] iOS 시뮬레이터 Debug 빌드·실행, 샘플 서가 내부 넘김·경계 왕복 및 사진 보관함 저장 통합 테스트. Galaxy A52s에서도 사진 보관함 저장 통합 테스트 통과.
- [x] iOS 실기기 Release 서명 빌드, 연결된 iPhone에 설치·앱 실행.
- [x] 이미지 저장·로그인·회원가입 화면을 로컬 폰트를 로드한 PNG로 렌더링해 시각 확인. Apple 버튼의 시스템 폰트는 호스트 캡처에서만 대체 폰트로 확인했다.

Android 샘플 서가의 동일한 측정 시나리오(각 140프레임)에서 평균 UI 구성 시간은 11.122ms → 4.042ms, 99백분위는 138.140ms → 69.174ms로 줄었다. 평균 GPU 그리기는 15.823ms → 15.744ms로 큰 변화가 없었다. 이 결과는 모든 프레임의 매끄러움이나 실계정 76권에서의 동일한 수치를 보장하지 않는다. 원본 수치는 `output/device-qa/2026-11-08/final-integration/`에 로컬 보관한다.

## 남은 확인

- [ ] **실제 소셜 로그인·두 계정 전환:** Android 통합 검증에서 `flutter drive`의 기본 종료 처리로 앱이 제거돼 로컬 로그인 정보가 초기화됐다. 보안 저장소 마이그레이션 로그도 있었지만 초기화 원인은 테스트 도구의 앱 제거 동작이다. 이후 테스트에는 `--keep-app-running`을 명시한다. 실계정 흐름은 재로그인이 필요하다. 현재까지 서버 책/기록을 변경하는 재검증은 하지 않았으며, 실제 소셜 로그인 입력은 사용자가 수행해야 한다. 위의 모의 응답 검증과 구분한다.
- [ ] **서버 수정·배포 후 재검증:** 최신 날짜 TODO 이유 선택, 결과 없음/검색 500 구분, 같은 날짜 기록의 안정적 정렬. [재현·기대 결과·완료 조건](../requests/2026-11-08-server-followups.md).
- [ ] **GPU 성능 추가 개선:** 샘플 기기에서 일부 프레임의 그리기 지연이 남아 있다. UI 구성 비용 감소와 별개로 추적한다.

## 검증 경계

실제 OAuth 제공자 화면 입력·두 번째 계정 전환, 실제 푸시 수신, iPhone에서 물리적인 책 바코드 인식은 이번 자동 통합 테스트에서 완료했다고 주장하지 않는다. 바코드의 앞선 사용자 성공 확인은 기존 QA 기록을 참고한다. 보관함 저장 테스트는 검증용 이미지를 추가한다. 스토어 업로드와 원격 저장소 푸시는 이번 정리 작업에 포함하지 않는다.

이전 작업부터 미추적이었던 `docs/requests/2026-10-09-moabook-backend-api-request.md`는 이번 변경에 포함하지 않는다.
